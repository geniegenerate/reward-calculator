ตรวจสอบการแจกรีวอร์ด_

ตรวจผลการแจกรีวอร์ดรอบหนึ่ง โดยไม่ต้องเชื่อบริษัท ทุกอย่างคำนวณในหน้านี้บนเครื่องของคุณ สิ่งเดียวที่หน้านี้ติดต่อคือ Bitcoin explorer สาธารณะ

คำนวณบนเครื่องคุณ อ่านจาก Bitcoin เท่านั้น ซอร์สโค้ดคือหน้านี้
  1. 01 หลักฐาน

    วางไฟล์ของรอบที่ต้องการตรวจ

    ต้องใช้สองไฟล์: Input Snapshot (ดาวน์โหลดจากแอป: ตรวจสอบรีวอร์ด → ดาวน์โหลดข้อมูลการตรวจสอบ) และ บันทึกสาธารณะ ของวันเดียวกัน (ไฟล์ public-record หรือไฟล์ .ots) วางไฟล์ผลลัพธ์ หรือ calculator.wasm จาก GitHub release เพิ่มได้

    วางไฟล์ที่นี่ หรือคลิกเพื่อเลือก input-snapshot.json · public-record.json หรือ .ots · result.json · calculator.wasm
  2. 02 โปรแกรม

    โปรแกรมคำนวณตัวจริง ระบุด้วยค่าแฮช

    keccak256 ของไฟล์ด้านล่าง คือ algorithm_id ซึ่งประกาศและประทับเวลาไว้อย่างน้อย 7 วัน ก่อนนำมาใช้คำนวณ ใครก็ตรวจซอร์สโค้ดได้ก่อน

  3. 03 ผลตรวจ

    คำนวณซ้ำ แล้วเทียบกับบันทึกใน Bitcoin

    หน้านี้คำนวณ Merkle root ทั้งสองค่าใหม่ สร้างข้อความของวันนั้นขึ้นใหม่เอง แล้วตรวจว่าแฮช SHA-256 ของข้อความนั้นคือค่าที่ถูกประทับเวลาไว้ใน Bitcoin ก่อนจ่ายรีวอร์ด

    คำนวณบนเครื่องคุณ จากหลักฐานประทับเวลาและ Bitcoin
